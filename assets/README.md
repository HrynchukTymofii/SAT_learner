# assets/ — brand source images (not used by code)

The app and website have their own copies of everything they use (`app/assets/`, `website/public/`).
This folder keeps source files for future design work.

In git: early logo/icon renders (`Untitled design*.png`, `SAT.png`, `.ico`) and `email/reply.html`
(HTML template used for answering support emails by hand).

Only on the original computer (too big or private, hand over as a zip): `icon.png`, `adaptive-icon.png`,
`ios-*.png`, `splash-icon-*.png` (current app icon sources), `app store/` and `play store/` (store listing
images), `problems/` and `tasks_images/` (question images used while building the course),
`SAT-Kaplan Test Prep.pdf` (reference book; licensed material, don't publish).
